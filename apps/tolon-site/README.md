# Tolon site

The static results page of the Tolon icon poll, which is closed. Peek won. There is no backend,
no database and no form: nginx serves the files in `web/`.

The poll had 18 voters. It was an email-verified poll with a Go service, SQLite, Cloudflare
Turnstile and Resend. All of that is removed. The last version of the service is in git history,
under `apps/tolon-poll/`.

## What it serves

`tolon.<domain>` through the Cloudflare tunnel. The container publishes no ports.

| Path | What |
|------|------|
| `/` | The results: winner, the other icons ranked by favorites, reactions as numbers and bars, total voters, a note about what happens next |
| `/preview/` | The real Tolon UI, built for the browser with a fake Tauri shim (see "Rebuild the preview") |
| `/pool`, `/pool/results` | Redirect to `/` (the old poll paths) |
| `/api/*` | `404` |
| `/healthz` | `200` for the container health check |

Only totals are published (`web/results.json`: favorites and reaction counts per icon, and the
number of voters). No emails and no comments are in the repository or on the site.

## Languages

Ten languages: pt-BR, de, en-US, es, ar, tr, hi, zh-CN, ja and he. The language comes from `?lang=`,
then the saved choice (`localStorage`), then the browser language, then en-US. A flag switcher in
the top bar changes it. Arabic and Hebrew are right to left.

| Path in `web/` | Content |
|----------------|---------|
| `index.html` | The page. The English results are pre-rendered in it, so curl and crawlers see them |
| `results.js` | Builds the results markup. `tools/build-results.mjs` runs it for the English page, the browser runs it for the other languages |
| `results.json` | The final counts |
| `i18n.js`, `i18n/<locale>.json` | Picks the language and holds the page texts |
| `options.json`, `options.<locale>.json` | Icon ids, images, names and taglines per language |

After a change to a text, `results.json` or `results.js`, run from the repository root:

```bash
node apps/tolon-site/tools/check-i18n.mjs        # every locale has the same keys and placeholders, copy rules hold
node apps/tolon-site/tools/build-results.mjs     # pre-renders the English page into index.html
node apps/tolon-site/tools/stamp-assets.mjs      # adds ?v=<hash> to css and js URLs in the HTML
```

## Server

`nginx.conf` is mounted into `nginxinc/nginx-unprivileged` (pinned by digest in `docker-compose.yml`).
The container runs as the nginx user with a read-only root filesystem, a `/tmp` tmpfs, no
capabilities, 64 MB of memory and its own `tolon` network, shared only with `cloudflared`.

- **Headers on every response**: CSP (`default-src 'self'`, no external origin, `frame-ancestors 'none'`),
  `nosniff`, `Referrer-Policy: no-referrer`, a Permissions-Policy that denies all features, and
  `Strict-Transport-Security: max-age=31536000` without `includeSubDomains`.
- **Caching**: HTML, and CSS, JS and JSON without a stamp, are `no-cache`. Files requested with
  `?v=<hash>` are `public, max-age=31536000, immutable`. Fonts and images keep the edge default.
- **Methods**: only GET and HEAD on pages. Other methods get 405 (404 under `/api/`).
- **Limits**: per visitor address (the `CF-Connecting-IP` header), 30 requests/s with a burst of 100, then 429.
  The Cloudflare rule in `terraform/ratelimit.tf` is the first layer: 100 requests per 10 s per IP and
  data centre, then a 10 s block. One page load is about 45 requests.
- **Logs**: the access log has time, method, path, status and size. No addresses, no user agents.

## Deploy

On the host, in the checkout of this repository:

```bash
git pull --ff-only
docker compose up -d tolon-site
docker ps --filter name=tolon-site          # healthy
```

Changes in `web/` and `nginx.conf` need no rebuild. After a change to `nginx.conf`, run
`docker compose restart tolon-site`.

### Rebuild the preview

`/preview/` is generated by `apps/tolon-site/preview-build/build.sh`. It builds the `ui/`
folder of the Tolon repository for the browser, adds a fake Tauri layer and a hand-written
shell, and writes the result to `apps/tolon-site/web/preview/`.

```bash
apps/tolon-site/preview-build/build.sh                       # pinned commit b178e08
apps/tolon-site/preview-build/build.sh --rev <commit>        # another Tolon commit
apps/tolon-site/preview-build/build.sh ~/src/tolon           # a local checkout
```

Usage is `build.sh [--rev <commit>] [path]`. Without a path it clones the Tolon repository
and checks out the commit (default `b178e08`). It needs git, node and npm, and it never
modifies a local checkout. nginx reads `web/` from disk on each request, so no
container restart is needed. Commit the new `web/preview/`.
